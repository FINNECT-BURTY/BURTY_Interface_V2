# BERTY 화면(IA) 정의서

> **작성일**: 2026-05-09
> **대상**: 기획자 / 디자이너 / PO
> **버전**: v1.0
> **포맷**: 메뉴 4Depth 화면 정의서
> **참조**: `docs/BERTY-기능명세서.md`

각 화면은 백엔드 API 명세(`src/main/java/com/berty/**`)와 1:1 매핑됩니다. **인증 레벨**은 LEVEL_1(JWT) / LEVEL_2(단계 인증) / LEVEL_3(생체·고위험) 3단계입니다.
